## Dates

## Description

Built and deployed QRFix, a bilingual QR-based maintenance and issue-reporting MVP for apartments, offices, clinics, schools, restaurants, factories, warehouses, and rental properties.

Designed a low-cost serverless architecture using React, Vercel, Amazon API Gateway, AWS Lambda, DynamoDB, IAM, CloudWatch, AWS SAM, and CloudFormation. Implemented ticket creation, filtering, priority management, and OPEN -> IN_PROGRESS -> RESOLVED workflows. Verified the deployment through CloudWatch logs and Lambda metrics.

Live demo: https://qrfix-omega.vercel.app

## LinkedIn post draft

I built and deployed QRFix, a bilingual QR-based maintenance and issue-reporting MVP designed for apartments, offices, clinics, schools, restaurants, factories, warehouses, and rental properties.

The goal was to build a practical cloud project with a low operating cost and no always-on server.

Architecture:
- React and Vite frontend on Vercel
- Amazon API Gateway REST API
- AWS Lambda with Node.js 22 on arm64
- Amazon DynamoDB on-demand
- CloudWatch logs and metrics
- IAM permissions
- AWS SAM and CloudFormation for Infrastructure as Code

The application supports QR-based reporting, Bangla and English, priority levels, ticket statistics, and OPEN -> IN_PROGRESS -> RESOLVED status management.

Live demo: https://qrfix-omega.vercel.app
GitHub: https://github.com/Zamshed87/qrfix-serverless
