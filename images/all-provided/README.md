# Screenshot archive

This directory contains all screenshots supplied during the QRFix implementation conversation.

Public-portfolio redaction has been applied to visible account identifiers, local paths, API endpoints, generated resource identifiers, device authorization details, and other sensitive or unnecessary values. The original screenshots are intentionally not included.

The EKS and non-QRFix S3 screenshots are retained only because they were part of the supplied image set. They are not referenced by the QRFix README.
